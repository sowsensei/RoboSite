🚀 Как установить и войти
  1. Скачай файл MineLauncher.exe и два раза щёлкни по нему. Устанавливать ничего не нужно.
  2. Windows может показать синее окно «Система Windows защитила ваш компьютер» — это нормально, не пугайся. Нажми кнопку «Выполнить в любом случае» (если кнопки нет — сначала нажми «Подробнее»).
  3. Придумай себе ник английскими буквами (можно цифры и _, от 3 до 16 символов). Например: Misha2018. Лаунчер запомнит ник — второй раз вводить не нужно.
  4. Сообщи свой ник учителю — он добавит тебя в список игроков сервера. Пока тебя нет в списке, сервер не пустит.
  5. Нажми зелёную кнопку ИГРАТЬ. Первый раз игра будет скачиваться несколько минут — внизу видна полоска загрузки. Не закрывай окно.
  6. Windows может спросить разрешение для «OpenJDK Platform Binary» — нажми «Разрешить доступ». Это нужно, чтобы игра могла подключиться к серверу.
  7. Игра откроется и сама зайдёт на наш сервер.
🔑 Пароль на сервере

В первый раз, когда зашёл в игру, открой чат клавишей T и напиши:

/register твойпароль твойпароль

(один и тот же пароль два раза через пробел). Запомни этот пароль!

В следующие разы при входе пиши:

/login твойпароль

💡 Придумай простой пароль и запиши его. Если забыл — напиши учителю, он сбросит.

⚠️ Если не работает
  • Проверь интернет и попробуй ещё раз — лаунчер сам докачает файлы.
  • Если пишет, что ник неправильный — проверь, что он английскими буквами.
  • Если сервер не пускает — напиши учителю: возможно, твой ник ещё не добавлен в список.
  • 💬 Написать учителю в MAX
📜 Правила
  1. Не ломай чужие постройки
  2. Не бери из чужих сундуков без разрешения
  3. Не используй читы и хаки
  4. Не оскорбляй других игроков в чате
  5. Спорные ситуации — к учителю, не выяснять самим
  6. За нарушения — кик или бан

Для родителей: лаунчер скачивает игровые файлы только с официальных серверов Mojang, не содержит рекламы и сторонних программ. Файлы игры хранятся в папке %APPDATA%\.minelauncher.
